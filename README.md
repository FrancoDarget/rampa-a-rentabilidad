# Rampa a Rentabilidad

Calculadora de escenario, punto de equilibrio y proyección de rentabilidad para negocios de e-commerce — pensada para usar en reuniones con clientes potenciales.

Incluye:
- Escenario de facturación, pauta (US$ / CAC / ROAS) y utilidad neta objetivo, todos enlazados en vivo.
- Punto de equilibrio ("piso antes de la comisión") y comparación de P&L.
- Costos fijos del cliente (sueldos, oficina, etc.).
- COGS por % de facturación o precio por unidad.
- Visualización en USD o ARS con tipo de cambio editable.
- Plan de escalado mensual opcional.

Todo corre 100% en el navegador (sin backend); los datos ingresados quedan solo en `localStorage` de quien la usa.

## Uso

Abrí `index.html` en cualquier navegador, o entrá a la versión publicada en GitHub Pages.
